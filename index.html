🔍 What is SIEM?

SIEM collects, analyzes, and correlates log and event data from security devices and applications across an organization's network. It's used primarily for threat detection, compliance, and security incident management.

Key Components

  • Log collection and normalization
  • Event correlation
  • Alerting and dashboards
  • Retention and forensic analysis
