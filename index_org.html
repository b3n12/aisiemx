🔍 What is SIEM?

SIEM collects, analyzes, and correlates log and event data from security devices and applications across an organization’s network. It’s used primarily for threat detection, compliance, and security incident management.

Key Components of SIEM:

  • Log collection and normalization
  • Event correlation
  • Alerting and dashboards
  • Retention and forensic analysis

🛡 What is XDR?

XDR is a unified security platform that automatically collects and correlates data across multiple security layers (endpoints, servers, network, cloud) to provide extended detection and response capabilities.

Key Components of XDR:

  • Endpoint, network, and cloud telemetry
  • Automated detection and correlation
  • Centralized visibility
  • Threat intelligence integration

⚙️ What is SOAR?

SOAR platforms help security teams automate and coordinate incident response workflows. They combine threat intelligence, playbooks, and case management tools to streamline security operations.

Key Components of SOAR:

  • Security orchestration and automation
  • Incident management
  • Threat intelligence ingestion
  • Playbooks and workflow automation
